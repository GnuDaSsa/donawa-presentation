# 도나와 발표자료

도마뱀 모프와 가격 비교 서비스 **도나와**의 HTML 발표자료입니다.

## 발표

`index.html`을 브라우저로 열면 발표 모드로 실행됩니다.

- 방향키, 스페이스바 또는 화면 클릭으로 슬라이드 이동
- `?all`을 붙이면 전체 슬라이드를 세로로 확인
- 전체 화면: `F`

## 구성

- `index.html`: 발표 덱 구조
- `deck-player.js`: 발표 전환 및 키보드 조작
- `deck.css`, `styles.css`: 슬라이드 스타일
- `assets/`: 발표에 사용하는 이미지와 GIF
- `도나와_발표자료.pdf`: PDF 버전

## 검증

`render.mjs`로 슬라이드를 렌더링하고 `qa.mjs`로 오버플로우를 검사할 수 있습니다.
